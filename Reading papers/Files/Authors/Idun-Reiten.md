# Idun Reiten

## 关联论文

- [Acyclic Quivers of Finite Mutation Type](<../../cluster/buan2006.md>)（local PDF retained）

## 身份核验

- 核验等级：中高。
- 公开资料一致指向 Idun Reiten（1942-2025），挪威数学家，长期在 University of Trondheim / NTNU 数学环境中工作。
- 公开资料显示其 1971 年在 University of Illinois 获博士，论文为 `Trivial Extensions and Gorenstein Rings`，研究领域包括 Artin algebras 表示论、同调代数、交换代数。
- QWiki 当前论文 `Acyclic Quivers of Finite Mutation Type` 与 Buan 官方出版物列表中的 Buan-Reiten 同名论文吻合。
- 本档案中关于逝世日期和早期履历来自公开资料，建议后续再以 NTNU memorial 或 IMU/Oberwolfach 条目复核。

## 学术历史

- Reiten 是 Auslander-Reiten theory 的核心人物之一；与 Maurice Auslander、Sverre Smalø 的工作构成 Artin algebra 表示论的基本语言。
- 1990 年代以后，她的 tilting/quasitilted algebra 传统自然进入 cluster category 方向。
- 与 Buan、Marsh、Reineke、Todorov 等合作的 `Tilting Theory and Cluster Combinatorics` 把 cluster algebra 与 tilting theory、cluster category 直接连接起来。
- QWiki 当前 `Acyclic Quivers of Finite Mutation Type` 可放在这条线中看：它处理的是 quiver mutation class 的有限性判别，背后是 cluster algebra 与表示论之间的桥。

## 学术品位

Reiten 的品位是“用同调结构控制表示论”。她关心的不只是分类，而是分类背后的 exact sequences、almost split sequences、AR quivers、tilting objects 和范畴等价。她进入 cluster 方向后，cluster combinatorics 获得了很强的表示论解释力。

## 研究风格

- 同调代数和范畴语言非常核心：几乎所有结构都通过 exact/triangulated/category-theoretic 语言被组织。
- 对 cluster algebra 的贡献偏“解释型”：用 category 和 representation theory 告诉你 mutation 为什么自然。
- 与 Buan 的论文适合作为从 Fomin-Zelevinsky combinatorics 转入 cluster category 的桥。
