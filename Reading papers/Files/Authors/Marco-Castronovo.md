## 学术历史

- 可核验的论文链条显示 Castronovo 的核心方向在 symplectic topology、Fukaya categories、homological mirror symmetry、Grassmannian Landau-Ginzburg mirrors 和 Lagrangian tori。
- `Fukaya category of Grassmannians: rectangles` 研究 Gelfand-Cetlin torus fiber、Grassmannian Fukaya category 的 summand 生成问题，并使用 Marsh-Rietsch mirror。
- `Exotic Lagrangian tori in Grassmannians` 通过 Marsh-Rietsch mirror 的 cluster algebra 结构构造 Grassmannian 中的 Lagrangian tori。
- 在 `Cluster deep loci and mirror symmetry` 中，他的背景解释了论文为何能把 cluster deep loci 与 Fukaya category split-generation / homological mirror symmetry 连接起来。

## 学术品位

Castronovo 的品位是“用 cluster / mirror 坐标控制 Fukaya category”。他关心的不是 cluster variety 作为纯代数对象，而是 cluster charts、Landau-Ginzburg potentials、Schur polynomial evaluations、Lagrangian tori 如何一起给出 Fukaya category 的生成与镜像对称证据。

## 研究风格

- 从 Grassmannian mirror 和 Fukaya category 的具体问题切入，再用 cluster 结构组织可计算对象。
- 喜欢用 torus fibers、Laurent polynomials、Schur polynomials、roots of unity 等具体数据来判断生成性和非位移性。
- 对 QWiki 的用法：把他看作当前 `Cluster Deep Loci` 论文中“镜像对称/辛拓扑解释”的关键声音。
