# Braiding structures on categorical multi-Interval Jones-Wassermann subfactor

## 基本信息

- arXiv: [2607.08296](https://arxiv.org/abs/2607.08296)

## 一句话概括

文章为任意 unitary modular fusion category 的多区间 Jones-Wassermann 子因子平面代数构造编织结构，用它重新证明自对偶性，并得到 balanced superelliptic mapping class group 的射影酉表示及广义 Verlinde 公式。

## 核心问题

若每个 modular fusion category 都应来自某种 CFT，那么 CFT 侧的 permutation orbifold、Jones-Wassermann subfactor、Fourier transform、高亏格映射类群表示等结构应当有纯范畴版本。本文问：多区间 Jones-Wassermann 子因子的 planar algebra 中能否显式构造这些 braiding operators？

## 主要贡献

- 对任意 UMFC 构造 multi-interval Jones-Wassermann subfactor planar algebra 上的 explicit braiding structures。
- 将 Liu-Xu 的 categorical Fourier transformation 表示为 braiding operators 的组合，从而给出 self-duality 的新证明。
- 证明这些 braidings 诱导 balanced superelliptic mapping class group 的 projective unitary representation。
- 用 planar tangles 和 isotopy identities 系统分析高亏格对称性。
- 计算 multi-interval Jones-Wassermann planar algebra 的 2-box convolution product structure constants。
- 将 generalized Verlinde formula 解释为 planar algebra 的 2-box Fourier duality。

## 方法与思路

这篇非常图解化：

```text
UMFC data
  -> configuration spaces Conf(C)_{m,n}
  -> multi-interval Jones-Wassermann planar algebra
  -> braiding operators on configuration spaces
  -> Fourier transform as product of braidings
  -> self-duality of subfactors
  -> mapping class group representation
  -> generalized Verlinde formula
```

它把 CFT/子因子里的几何构造翻译成 modular fusion category 和 planar algebra 的图形演算。

## 关键概念

- UMFC：unitary modular fusion category。
- Jones-Wassermann subfactor：来自 conformal net/CFT 的经典子因子结构，这里被范畴化。
- planar algebra：子因子计算的图形语言。
- categorical Fourier transform：Liu-Xu 构造中用于证明自对偶性的关键算子。
- balanced superelliptic mapping class group：由 cyclic branched cover 上的可提升 braid 产生的映射类群。
- generalized Verlinde formula：把结构常数写成 modular data 的高维/多区间对应。
