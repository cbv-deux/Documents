# Factorization Algebras and Quantum Groups from Generalized Poisson Sigma Models

## 基本信息

- 中文标题：从广义 Poisson sigma 模型得到的因子化代数与量子群

## 一句话概括

文章把高维全纯-拓扑版 Poisson sigma 模型组织为由 shifted chiral Poisson 结构控制的场论，并用因子化代数、边界/缺陷与 Koszul 对偶导出各种量子群结构。

## 核心问题

经典二维 Poisson sigma model 与形变量子化关系很深。本文问的是：若把它推广到高维 holomorphic-topological setting，bulk theory、factorization algebra、boundary algebra、defect 与 quantum group 之间是否仍有系统对应？

## 主要贡献

- 引入 generalized Poisson sigma models，作为二维 Poisson sigma model 的高维全纯-拓扑类似物。
- 用 shifted chiral Poisson structures 编码靶数据。
- 研究这类理论与 holomorphic-topological factorization algebras 的 deformation quantization 的关系。
- 系统构造 interfaces、enriched boundaries、defects 等 extended objects。
- 用 derived algebraic geometry 的语言描述 Poisson morphism、Poisson module、coisotropic module 等边界/缺陷数据。
- 通过 Koszul duality 分析 boundary algebras，并得到 quasi-Hopf、quantized enveloping algebra、quasi-triangular 结构、Yangian 边界等例子。
- 把框架应用到 supersymmetric gauge theories 的 twists 以及非超对称来源的例子。

## 方法与思路

这篇是“对象-函子-边界代数”的大框架论文。它不是只证明一个孤立定理，而是建立一条构造链：

```text
shifted chiral Poisson data
  -> generalized Poisson sigma model
  -> holomorphic-topological factorization algebra
  -> interfaces / enriched boundaries / defects
  -> boundary algebra and higher brackets
  -> Koszul dual algebra
  -> quantum group / quasi-Hopf / Yangian-type object
```

精读时最要紧的是逐段标出每个箭头需要的假设，而不是一开始就陷入所有 Feynman integral 的细节。

## 关键概念

- factorization algebra：把局部可观测量按嵌套开集组织起来的代数结构。
- shifted chiral Poisson structure：全纯-拓扑场论靶空间上的 Poisson 型数据。
- enriched boundary：带额外代数结构的边界条件，能产生边界代数。
- Koszul duality：从边界代数到量子群结构的核心机制。
- quasi-Hopf algebra / Drinfeld associator：从 3d/4d 理论边界中出现的量子代数对象。
- Yangian at the boundary：Costello 系列 gauge theory/integrability 语言的延伸。

## 与用户偏好的关系

这是强命中：TQFT/全纯-拓扑场论、因子化代数、边界与缺陷、Koszul 对偶、量子群全部在同一条链上。它非常适合作为“从物理场论构造量子代数”的核心入口。

## 疑问与后续阅读

- shifted chiral Poisson structure 的最小定义体系需要单独补。
- Koszul dual 得到的 quantum group 与 E_n/Koszul duality 的一般定理之间关系需要整理。
- 和 Costello-Gaiotto、Costello-Witten-Yamazaki 的 gauge theory/integrability 线有明显连接，值得并行建立背景档案。
