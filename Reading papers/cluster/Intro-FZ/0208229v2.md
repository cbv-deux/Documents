# Cluster Algebras II: Finite Type Classification

- 作者：Sergey Fomin, Andrei Zelevinsky
- 日期：2003-03-12
- 来源：[arXiv:math/0208229v2](https://arxiv.org/abs/math/0208229)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `Intro-FZ/0208229v2.pdf`。

## 核心问题

第二篇解决 finite type classification：cluster variables 有限当且仅当 exchange matrix 的 Cartan counterpart 属于有限型 Dynkin 图。它把 cluster algebra 的有限性与根系分类直接连接。

## 主线

文章从 pseudomanifold 和 exchange graph 入手，构造 generalized associahedra，并证明 finite type 对应 Dynkin 类型。随后描述 finite type 中 cluster variables 与 almost positive roots 的对应，并给出各型的几何实现。

## 我需要记住的技巧

- finite cluster type = Dynkin type，这是 cluster theory 最重要的分类结果之一。
- almost positive roots 是有限型 cluster variables 的组合模型。
- generalized associahedron 把交换图变成凸多面体/组合几何对象。

## 阅读建议

重点读 Theorem 1.4 附近的分类陈述，以及 cluster variables 与 roots 的对应。证明细节可以配合 Dynkin 图例子慢慢消化。
