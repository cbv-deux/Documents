# Cluster Algebras I: Foundations

- 作者：Sergey Fomin, Andrei Zelevinsky
- 日期：2001-04-13
- 来源：[arXiv:math/0104151v1](https://arxiv.org/abs/math/0104151)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `Intro-FZ/0104151v1.pdf`。

## 核心问题

这是 cluster algebra 的第一篇奠基文。它引入 cluster、cluster variable、seed mutation、exchange relation，并证明 Laurent phenomenon：任何 cluster variable 在任意一个 cluster 中都是 Laurent 多项式。

## 主线

文章从希望理解 dual canonical bases 与 total positivity 的动机出发，定义 exchange pattern 和 cluster algebra。Rank 2 和 exchange graph 的例子说明了 mutation 的基本几何。核心定理 Laurent phenomenon 说明看似有分母的迭代突变不会产生任意有理函数，而始终保留强整性。

## 我需要记住的技巧

- exchange relation 是 cluster algebra 的发动机。
- Laurent phenomenon 是整个理论可计算性的基础。
- cluster algebra 一开始就和 total positivity、canonical basis、半单群坐标有关。

## 阅读建议

第一遍只读定义、例子和 Laurent phenomenon 的陈述。证明可以第二遍再看。所有后续 cluster 文献都默认你熟悉这篇的语言。
