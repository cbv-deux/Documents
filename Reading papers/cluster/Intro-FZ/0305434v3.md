# Cluster Algebras III: Upper Bounds and Double Bruhat Cells

- 作者：Arkady Berenstein, Sergey Fomin, Andrei Zelevinsky
- 日期：2004-01-21
- 来源：[arXiv:math/0305434v3](https://arxiv.org/abs/math/0305434)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `Intro-FZ/0305434v3.pdf`。

## 核心问题

第三篇引入 upper cluster algebra，并证明在 acyclic 条件下 cluster algebra 与 upper cluster algebra 相等且有限生成。另一条主线是把 semisimple group 的 double Bruhat cells 的坐标环识别为 upper cluster algebra。

## 主线

文章先定义 upper bound 和 lower bound，研究 seed mutation 下的不变量；然后用 acyclicity 关闭 cluster algebra 和 upper cluster algebra 的差距。第二部分把 double Bruhat cells 中的 generalized minors、reduced words 和 combinatorial data 转化为 cluster seed。

## 我需要记住的技巧

- upper cluster algebra 是所有 cluster Laurent rings 的交。
- acyclic seed 是很多代数性质成立的关键假设。
- double Bruhat cells 是 cluster structures 在 Lie theory 中的核心来源。

## 阅读建议

先读 upper cluster algebra 的定义和 acyclic equality。再回头对照 FZ total positivity 与 BFZ minors 看 double Bruhat cells 的部分。
