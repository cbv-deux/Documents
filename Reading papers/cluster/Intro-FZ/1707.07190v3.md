## 核心问题

这份教材草稿继续 cluster algebra 基础，进入更系统的系数、几何型、交换图和有限型组合。它是从定义走向分类与结构理解的桥。

## 主线

Chapters 4-5 主要扩展前 3 章的基础语言，把 coefficients、patterns、finite type combinatorics 和相关例子组织起来。它帮助读者理解为什么同一个 mutation 规则可以在代数、组合和几何模型中反复出现。

## 我需要记住的技巧

- coefficients 不是附加细节，而是控制 frozen variables 和几何模型的关键。
- finite type 的组合结构需要和 exchange graph、root system 一起看。
- 教材路线比原始分类论文更适合查缺补漏。

## 阅读建议

适合在 FZ I 后、FZ II 前读。把 coefficients 和 finite type 的基本例子弄清楚，再读分类证明。
