# Double Bruhat Cells and Total Positivity

- 作者：Sergey Fomin, Andrei Zelevinsky
- 日期：1998-02-11
- 来源：[arXiv:math/9802056v1](https://arxiv.org/abs/math/9802056)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `Intro-FZ/9802056v1.pdf`。

## 核心问题

这是 cluster algebras 诞生前的重要前史。文章研究 semisimple group 中 double Bruhat cells 与 total positivity，给出 generalized minors、factorization parameters、twist maps 和 positivity criteria。

## 主线

文章从 Lusztig 的 total positivity 出发，研究 $G^{u,v}$ 这样的 double Bruhat cells。核心是用 generalized minors 和 reduced words 给出坐标与判别条件。后来的 cluster seed、exchange relation 和 double Bruhat cell cluster structure，很大程度上从这里的坐标组合中长出来。

## 我需要记住的技巧

- double Bruhat cell 是 total positivity 与 cluster algebra 的共同源头之一。
- generalized minors 是 Lie theory 中的 cluster 变量前身。
- twist map 是理解正性和因子分解的关键变换。
