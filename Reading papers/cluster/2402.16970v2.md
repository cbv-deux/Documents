## 核心问题

这篇文章问的是：cluster charts 看不到的 deep locus 到底是什么。作者提出“no mysterious points”猜想，把 deep locus 解释为 cluster automorphism 作用下有非平凡稳定子的点集。直观上，cluster atlas 像一套由代数环面拼起来的坐标系统；deep locus 是所有这些环面图都避开的地方，往往携带奇点或镜像对称中的关键临界点。

## 主线

文章先把 affine cluster variety、upper cluster variety、locally acyclic 等背景整理成 deep locus 的语言，然后证明在若干有限型和 positroid 型例子中，deep locus 等于 stabilizer locus。技术核心是把相关 cluster varieties 实现为 braid varieties，并用 Demazure weaves 构造足够多的 cluster charts。最后把这个结论推回 Grassmannian 的 Landau-Ginzburg mirror，说明当 deep locus 消失或可控时，Fukaya category 的生成问题也变得可控。

## 我需要记住的技巧

- deep locus 不是“坐标不好”的小毛病，而是 cluster atlas 的结构性盲区。
- stabilizer locus 给了一个内禀判据：不是枚举所有 cluster charts，而是看 cluster automorphism 的自由性。
- weaves 的作用像是一种组合化的图谱生成器，用来证明某些点确实落在某个 cluster chart 里。
- 对 mirror symmetry 来说，cluster charts 对应 Lagrangian tori；deep locus 中的临界点会影响 Fukaya category 的生成。
