# Dual Teichmuller and Lamination Spaces

- 作者：Vladimir Fock, Alexander Goncharov
- 日期：2005-10-14
- 来源：[arXiv:math/0510312v1](https://arxiv.org/abs/math/0510312)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `FG/0510312v1.pdf`。

## 核心问题

这是一篇 survey 风格的文章，解释 open surfaces 上两种 Teichmuller 空间与 lamination 空间如何成对出现，并如何用 $A$ 与 $X$ 两套坐标描述。它适合作为 Fock-Goncharov 大文的入门侧门。

## 主线

文章从曲面的 Teichmuller space 与 measured laminations 出发，讨论边界点、puncture、marked point 的不同版本。然后给出坐标、mapping class group action、Poisson 或 symplectic 结构，并解释 lamination space 是 Teichmuller space 的 tropical limit。最后构造 lamination 与 Teichmuller 空间之间的 canonical pairing。

## 我需要记住的技巧

- lamination 是 Teichmuller 坐标的 tropical 影子。
- $A$ 与 $X$ 的双版本在曲面场景下有清楚几何解释。
- canonical pairing 是把 integral lamination 变成 Teichmuller 空间上函数的机制。

## 阅读建议

如果 higher Teichmuller 大文太重，先读这篇。把它当成“曲面 cluster 坐标 + tropical lamination”的概念地图。
