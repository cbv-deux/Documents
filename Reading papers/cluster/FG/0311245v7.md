# Cluster Ensembles, Quantization and the Dilogarithm

- 作者：Vladimir Fock, Alexander Goncharov
- 日期：2009-08-04
- 来源：[arXiv:math/0311245v7](https://arxiv.org/abs/math/0311245)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `FG/0311245v7.pdf`。

## 核心问题

这篇文章系统化了 cluster ensemble 的语言：每个 seed 同时给出 $A$-torus 与 $X$-torus，二者由自然映射连接；mutation 给出可拼接的代数空间。量子化时，$X$ 空间变成 quantum torus，而 quantum dilogarithm 控制 mutation 的一致性。

## 主线

前半部分定义 cluster $A$-variety、cluster $X$-variety、cluster modular group 和 ensemble map。后半部分转向量子化：把 Poisson bracket 变成非交换变量关系，再用 quantum dilogarithm 处理突变算子的 pentagon identity。最后的 duality 和 canonical pairing 猜想把这套结构推向 canonical basis 与 motivic dilogarithm。

## 我需要记住的技巧

- cluster ensemble 是同时看 $A$ 与 $X$ 的框架，不只是一个 cluster algebra。
- $X$ 空间天然带 Poisson 结构，适合量子化。
- quantum dilogarithm 是 mutation 在量子层面保持一致的核心函数。
- cluster modular group 是研究坐标变换、mapping class group 和量子表示的统一入口。

## 阅读建议

先读定义和例子，尤其 $M_{0,n+3}$ 与小型 Dynkin 类型。量子部分先抓 pentagon identity 的角色，不必一开始追所有分析细节。
