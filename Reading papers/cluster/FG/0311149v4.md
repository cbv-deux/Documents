# Moduli Spaces of Local Systems and Higher Teichmuller Theory

- 作者：Vladimir Fock, Alexander Goncharov
- 日期：2006-04-29
- 来源：[arXiv:math/0311149v4](https://arxiv.org/abs/math/0311149)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `FG/0311149v4.pdf`。

## 核心问题

这是 Fock-Goncharov 高 Teichmuller 理论的奠基长文。它把曲面上的 $G$-local systems 的模空间组织成带有正结构、cluster 坐标、lamination tropicalization 和 canonical pairing 的几何对象。传统 Teichmuller 空间只是 $G = PGL_2$ 的影子。

## 主线

文章构造两类模空间：$A_{G,S}$ 和 $X_{G,S}$，分别对应 decorated 与 framed local systems。核心思想是用 ideal triangulation 或更一般的组合数据给出正坐标；换三角剖分时坐标变换具有 subtraction-free 形式，因此可以做 tropicalization。这样，lamination、mapping class group action、Poisson 结构和 canonical bases 都进入同一个 cluster ensemble 视角。

## 我需要记住的技巧

- $A$ 空间更像带装饰的坐标环，$X$ 空间更像 Poisson/Teichmuller 侧。
- positivity 是连接实正点、tropical 点和 canonical basis 猜想的桥。
- 曲面切割带来的坐标变换就是 cluster mutation 的几何来源之一。
- higher Teichmuller theory 可以看成 cluster variety 在曲面 local systems 上的自然化身。

## 阅读建议

不要试图一次读完 222 页。先读 Introduction 的结构图，再读 Section 2 的模空间定义和 Section 9-10 的 cluster 坐标例子。真正理解 pairing 与 canonical bases 时，再读 lamination 后半部分。
