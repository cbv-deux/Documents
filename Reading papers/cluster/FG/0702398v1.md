# Cluster Ensembles, Quantization and the Dilogarithm II: The Intertwiner

- 作者：Vladimir Fock, Alexander Goncharov
- 日期：2007-02-13
- 来源：[arXiv:math/0702398v1](https://arxiv.org/abs/math/0702398)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `FG/0702398v1.pdf`。

## 核心问题

这是 cluster ensembles 量子化系列的短续篇，专门构造 intertwiner。它回答的问题是：不同 cluster 坐标图量子化后，如何在表示空间之间建立一致的变换。

## 主线

文章回顾 cluster ensembles 和 quantum $X$-varieties，然后从 $A$ 空间函数的 bimodule 结构出发，构造 intertwiner。quantum dilogarithm 再次负责处理非平凡 mutation，使不同坐标选择对应的表示相互兼容。

## 我需要记住的技巧

- intertwiner 是量子 cluster atlas 的坐标变换算子。
- 这篇比 v6 长文更集中，适合专门理解“算子如何变换”。
- $A$ 空间在这里不是配角，它提供了构造表示间变换的函数空间。
