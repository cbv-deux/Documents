# Cluster X-varieties, Amalgamation and Poisson-Lie Groups

- 作者：Vladimir Fock, Alexander Goncharov
- 日期：2006-01-06
- 来源：[arXiv:math/0508408v2](https://arxiv.org/abs/math/0508408)
- 本地 PDF：已由 arXiv 完全替代，清理时可删除 `FG/0508408v2.pdf`。

## 核心问题

这篇文章把 split semisimple Lie group 的 Poisson-Lie 结构放进 cluster $X$-variety 语言。重点不是从 $r$-matrix 出发，而是通过 elementary cluster varieties 和 amalgamation 拼出群、双 Bruhat cells 及相关 Poisson 坐标。

## 主线

作者为每个 simple root 构造 elementary cluster $X$-variety，再用 amalgamation 把它们按 reduced word 拼起来。这样得到的空间带有自然 Poisson 结构，并映到 Poisson-Lie group。对于某些 reduced word，这些坐标给出群的 birational chart。量子化后，amalgamation 对应非交换 quantum torus 的拼接。

## 我需要记住的技巧

- amalgamation 是 cluster variety 的“胶合乘法”，是从局部根数据拼全局群结构的工具。
- Poisson-Lie group 可以用 cluster 坐标重建，而不必先写传统 $r$-matrix。
- double Bruhat cells 是 cluster theory、total positivity 与 Poisson geometry 的交汇点。

## 阅读建议

这篇适合放在 FZ double Bruhat cells 之后读。先理解 amalgamation 的定义，再看它怎样恢复 Poisson-Lie group 的坐标。
