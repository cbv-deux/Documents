# Acyclic Quivers of Finite Mutation Type

- 作者：Aslak Bakke Buan, Idun Reiten
- 日期：2006
- 来源：International Mathematics Research Notices, 2006
- 本地 PDF：保留 `buan2006.pdf`。我没有确认到 arXiv 上存在完全同标题同版本 PDF。

## 核心问题

这篇短文给出 acyclic quiver 的 finite mutation type 判别：连通、无圈、至少三个顶点的 acyclic quiver，如果突变类有限，那么它必须是 Dynkin 或 extended Dynkin 型，反过来也成立。它把 Fomin-Zelevinsky 的 cluster mutation 问题和 hereditary algebra、representation type 的分类连接起来。

## 主线

文章的策略是把 skew-symmetric matrix mutation 翻译成 quiver mutation，再利用有限维代数表示论中关于有限型、驯型和野型的结构事实。对 acyclic quiver 而言，Dynkin 和 extended Dynkin 情况天然给出有限突变类；非 Dynkin/extended Dynkin 的 acyclic quiver 会在突变过程中产生无限多不同形状。

## 我需要记住的技巧

- finite mutation type 不等同于 finite cluster type；extended Dynkin 是关键边界。
- acyclic 假设非常强，它允许从 cluster combinatorics 转向 hereditary algebra。
- 这篇是“突变有限性”路线的极短判别工具，适合和 FZ finite type classification 对照读。

## 阅读建议

先把结论记成一句话：acyclic connected finite mutation type = Dynkin or affine Dynkin（至少三个顶点）。之后再回头看它如何使用表示论来排除其它 acyclic quiver。
